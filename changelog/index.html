Changelog

0.1.0 — 2026-10-26

First complete release:

  • Kanban board (Saved, Applied, Interview, Offer, Rejected) with drag and drop, keyboard reordering, and a mobile column view.
  • Job form with company, role, link, platform, type, rate, location, dates, notes, tags, and contact.
  • Proposal templates with {company}, {role}, {name}, and {skills} placeholders and copy to clipboard.
  • Follow-up reminders: overdue and due-today sections, plus optional browser notifications.
  • Search, filter by status, platform, and tag, and four sort orders.
  • Statistics: applications per week, response rate, and interview rate.
  • JSON export and import with validation and confirmation before overwrite.
  • Dark and light themes, keyboard shortcuts, first-run sample data, and PWA support.
  • Static landing page with privacy, about, and changelog pages, sitemap, robots.txt, and llms.txt.

Roadmap (not yet released)

Optional cloud sync with a private key, a browser extension, and optional bring-your-own-key AI drafts. See the README for details.
